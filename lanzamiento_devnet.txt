PRE-DEPLOYMENT (Local Testing)
───────────────────────────────────────────────────────────────────────────────

1. GENERATE PROGRAM KEYPAIRS
   
   $ solana-keygen new -o oxide-program.json
   $ solana-keygen new -o hook-program.json 
   
   ⚠️ SAVE THESE KEYPAIRS SECURELY - You'll need them for IDL updates
   
   Store the pubkeys:
   - OXIDE_PROGRAM_ID=$(solana address -k oxide-program.json)
   - HOOK_PROGRAM_ID=$(solana address -k hook-program.json)
   
   Output example:
   OXIDE_PROGRAM_ID=5amCTzFY...
   HOOK_PROGRAM_ID=HookProg...


2. UPDATE PROGRAM IDs IN SOURCE CODE
   
   In lib.rs (OXIDE main program):
   - Line 16: declare_id!("YOUR_OXIDE_PROGRAM_ID_HERE");
   
   In hook_lib.rs (Transfer Hook):
   - Line 15: declare_id!("YOUR_HOOK_PROGRAM_ID_HERE");
   
   In lib.rs (OXIDE constants):
   - Line 20: const HOOK_PROGRAM_ID: Pubkey = pubkey!("YOUR_HOOK_PROGRAM_ID_HERE");
   
   Example:
   declare_id!("5amCTzFY1j7PSfKfb4vvCvQeJJPXwRBCaZBVL8PZM4qV");


3. RUN ALL TESTS LOCALLY (IN THIS ORDER)
   
   Step A: Unit tests (fast, < 1 second)
   $ cargo test --test unit_tests -- --nocapture
   
   Expected: ✅ ALL PASS
   - Burn calculations (basic, zero, 1 day, max u64, fractional)
   - Timestamp tracking (weighted average, reset, inheritance)
   - Grace period logic (14:59, 15:00, 15:01 boundaries)
   - Supply caps (genesis 1000, daily 1%)
   
   
   Step B: Edge case tests (CRITICAL, < 10 seconds)
   $ cargo test --test edge_case_tests -- --nocapture --test-threads=1
   
   Expected: ✅ ALL PASS (Most important test suite)
   🔴 CRITICAL TESTS:
   - edge_case_max_u64_balance           → No overflow on max balance
   - edge_case_elapsed_negative          → Clock regression safe
   - edge_case_timestamp_overflow        → u64::MAX timestamps safe
   - edge_case_grace_period_boundary     → Exactly 15 min handling
   - edge_case_hook_program_id_immutable → Security constant
   
   
   Step C: Integration tests (with local validator)
   $ anchor test --skip-build
   
   Expected output:
   ✅ test_deposit_synchronizes_with_hook: PASS
   ✅ test_withdraw_applies_burn: PASS
   ✅ test_clear_debt_resets_timestamp: PASS
   ✅ test_pool_transfer_whitelist_bypass: PASS
   ✅ test_user_transfer_applies_burn: PASS
   ✅ test_delegate_transfer_blocked: PASS
   ✅ test_weighted_average_timestamp_inheritance: PASS
   ✅ test_hook_program_id_validation: PASS
   ✅ test_genesis_airdrop_with_1000_wallets: PASS
   ✅ test_daily_release_cap_enforced: PASS
   ✅ test_mint_authority_verification: PASS
   ✅ test_invalid_mint_rejected: PASS
   
   ⚠️ Do NOT proceed to DEVNET if any test fails


4. LINT & SECURITY CHECK
   
   $ cargo clippy --all-targets
   $ cargo audit
   $ anchor test --features anchor-debug (optional, for debugging)


5. BUILD FOR DEVNET
   
   $ anchor build
   
   Output:
   Build successful ✅
   - target/deploy/oxide.so
   - target/deploy/oxide_transfer_hook.so

DEVNET DEPLOYMENT
───────────────────────────────────────────────────────────────────────────────

6. CONFIGURE SOLANA CLI FOR DEVNET
   
   $ solana config set --url https://api.devnet.solana.com
   $ solana config get
   
   Output should show:
   RPC URL: https://api.devnet.solana.com
   WebSocket URL: wss://api.devnet.solana.com/ (computed)
   Keypair Path: ~/.config/solana/id.json
   Commitment: confirmed


7. REQUEST DEVNET SOL
   
   $ solana airdrop 10 $(solana address -k oxide-program.json)
   $ solana airdrop 10 $(solana address -k hook-program.json)
   
   Wait for airdrops to confirm:
   $ solana balance $(solana address -k oxide-program.json)
   $ solana balance $(solana address -k hook-program.json)
   
   Both should show ~10 SOL


8. DEPLOY HOOK PROGRAM FIRST
   
   ⚠️ CRITICAL: Deploy hook_lib.rs BEFORE lib.rs (hook is dependency)
   
   $ solana program deploy \
     --program-id hook-program.json \
     target/deploy/oxide_transfer_hook.so \
     --url https://api.devnet.solana.com
   
   Output example:
   Program deployed successfully to HookProg...
   
   Verify:
   $ solana program show --url https://api.devnet.solana.com HookProg...


9. DEPLOY OXIDE PROGRAM
   
   $ solana program deploy \
     --program-id oxide-program.json \
     target/deploy/oxide.so \
     --url https://api.devnet.solana.com
   
   Output example:
   Program deployed successfully to 5amCTzFY...
   
   Verify:
   $ solana program show --url https://api.devnet.solana.com 5amCTzFY...


10. CREATE SPL TOKEN-2022 WITH TRANSFER HOOK

      --program-id TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPvLZ8 \
      --transfer-hook HookProg... \
      --mint-authority $(solana address -k oxide-program.json) \
      --url https://api.devnet.solana.com
    
    Output:
    Creating token MINT_ID...
    Signature: ...
    Token address: YOUR_MINT_ID
    
    Save the MINT_ID for later steps


11. INITIALIZE GLOBAL STATE
    
    Use oxide_cli.py:
    $ python cli/oxide_cli.py \
      --program-id 5amCTzFY... \
      --mint YOUR_MINT_ID \
      --url https://api.devnet.solana.com \
      init-global
    
    Or via direct transaction (from tests/integration_tests.rs):

12. VERIFY HOOK IS ACTIVE
    
    $ spl-token display YOUR_MINT_ID \
      --url https://api.devnet.solana.com

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Issue: "Program failed to initialize" (InvalidHookProgram error)
→ Solution: Verify HOOK_PROGRAM_ID constant matches deployed hook_lib.rs

Issue: "Transaction exceeds CU limit"
→ Solution: Optimize loops in apply_lazy_burn() or split into multiple txs

Issue: "Pool transfer shows burn (should be 0%)"
→ Solution: Verify pool is whitelisted in is_whitelisted_owner_program()

Issue: "Transfer blocked with DebtNotCleared"
→ Solution: Call clear_debt() first if using delegates

Issue: "Genesis airdrop limit exceeded"
→ Solution: Genesis airdrop is capped at 1000 wallets total - this is by design

Issue: "Raydium/Orca pool not accepting OXD transfers"
→ Solution: Ensure token has transfer hook enabled and pool is initialized

Issue: "test_clock_regression_handling fails"
→ CRITICAL: Verify elapsed < 0 is handled (if elapsed < 0 { elapsed = 0 })
→ This edge case kills mainnet if not handled

Issue: "test_burn_with_max_u64_balance panics"
→ CRITICAL: Ensure u128 intermediate in burn calculation prevents overflow
