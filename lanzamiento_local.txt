FASE 2 – GENERAR KEYPAIRS DE PROGRAMA (SOLO PRIMERA VEZ)

4. Genera keypairs para los programas (si no existen)

   - Los necesitarás para actualizar el programa después


5. Obtén las direcciones de los programas
   
   $ OXIDE_PROGRAM_ID=$(solana address -k target/deploy/oxide-keypair.json)
   $ HOOK_PROGRAM_ID=$(solana address -k target/deploy/oxide_transfer_hook-keypair.json)
   
   $ echo "OXIDE Program ID: $OXIDE_PROGRAM_ID"
   $ echo "Hook Program ID: $HOOK_PROGRAM_ID"
   
   Ejemplo de salida:
   OXIDE Program ID: 5amCTzFY1j7PSfKfb4vvCvQeJJPXwRBCaZBVL8PZM4qV
   Hook Program ID: HookProg3xXxXxXxXxXxXxXxXxXxXxXxXxXxXxXxXxXx


6. Actualiza los Program IDs en el código fuente
   
   Abre lib.rs (programa OXIDE):
   - Línea ~16: declare_id!("TU_OXIDE_PROGRAM_ID_AQUI");
   
   Abre hook_lib.rs (programa Hook):
   - Línea ~15: declare_id!("TU_HOOK_PROGRAM_ID_AQUI");
   
   Abre lib.rs otra vez (constante HOOK_PROGRAM_ID):
   - Línea ~20: const HOOK_PROGRAM_ID: Pubkey = pubkey!("TU_HOOK_PROGRAM_ID_AQUI");
   
   ⚠️ CRITICAL: Los tres IDs deben coincidir EXACTAMENTE
   
   Ejemplo completo (reemplaza con tus IDs):
   
   En lib.rs (línea 16):
   declare_id!("5amCTzFY1j7PSfKfb4vvCvQeJJPXwRBCaZBVL8PZM4qV");
   
   En hook_lib.rs (línea 15):
   declare_id!("HookProg3xXxXxXxXxXxXxXxXxXxXxXxXxXxXxXxXxXx");
   
   En lib.rs (línea 20):
   const HOOK_PROGRAM_ID: Pubkey = pubkey!("HookProg3xXxXxXxXxXxXxXxXxXxXxXxXxXxXxXxXxXx");

FASE 6 – CREAR MINT TOKEN-2022 CON TRANSFER HOOK
───────────────────────────────────────────────────────────────────────────────

16. Crea el mint Token-2022 (6 decimales, con hook)
    
    $ spl-token create-token \
      --program-id TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxLZ8 \
      --decimals 6 \
      --url http://localhost:8899
    
    Output:
    Creating token <MINT_ID>
    
    Guarda el MINT_ID:
    $ export MINT_ID=<tu_mint_address>
    $ echo "Mint ID: $MINT_ID"


17. Inicializa la extensión transfer hook en el mint
    
    $ spl-token initialize-mint-extension \
      $MINT_ID \
      transfer-hook \
      $(solana address -k target/deploy/oxide_transfer_hook-keypair.json) \
      --url http://localhost:8899
    
    Expected: Hook extension initialized
    
    Verifica:
    $ spl-token display $MINT_ID --url http://localhost:8899
    # Output debe mostrar: Transfer Hook Program: HookProg...


18. Establece la mint authority al programa OXIDE (GLOBAL_PDA)
    
    Primero calcula el GLOBAL_PDA:
    $ pnpm run pda:global -- --program $(solana address -k target/deploy/oxide-keypair.json)
    
    Output:
    Global PDA: <GLOBAL_PDA_ADDRESS>
    
    $ export GLOBAL_PDA=<global_pda_address>
    
    Transfiere mint authority:
    $ spl-token authorize \
      $MINT_ID \
      mint \
      $GLOBAL_PDA \
      --url http://localhost:8899
    
    Verifica:
    $ spl-token display $MINT_ID --url http://localhost:8899
    # Mint authority: <GLOBAL_PDA>
